**Kumo** (蜘蛛 — *spider* in Japanese) is a terminal multiplexer that weaves
your AI agents together into a single **web**. Every pane is a live terminal,
every AI CLI you run (`opencode`, `claude`, `codex`, …) is a thread in that
web, and the sidebar keeps you aware of what each agent is doing at a glance —
because a spider always knows what's happening in its web.

It is built in **Rust** with a single TUI frontend on **ratatui**, real
terminal emulation from **libghostty-vt** (Ghostty's headless terminal core),
and **portable-pty** for PTY management. And it's featherweight: while you
work, kumo itself idles at **~0.7% CPU and ~6 MB of memory** — the real cost
is whatever you run *inside* its panes, not the multiplexer.

## Features

<Cards>
  <Card icon={<SquareTerminal />} title="Real terminal emulation">
    Each pane is a genuine VT/xterm emulator (vendored Ghostty). Shells, TUIs
    and full-screen apps behave exactly like in a native terminal.
  </Card>
  <Card icon={<Columns2 />} title="Split panes & sessions">
    Binary split tree, mouse-drag resizing, zoom, multiple independent
    sessions and tab cycling.
  </Card>
  <Card icon={<Bot />} title="AI CLI panes">
    Spawn a pane running your AI CLI with one keystroke, or run any agent in a
    shell pane: kumo detects it and weaves it into the sidebar.
  </Card>
  <Card icon={<Activity />} title="Agent status at a glance">
    A status dot per agent — green working, orange blocked, gray idle —
    detected from the live terminal buffer, accurate while you scroll.
  </Card>
  <Card icon={<Bell />} title="Audible alerts">
    A distinct chime when an agent blocks or finishes; blocked agents float to
    the top of the list and their pane glows orange.
  </Card>
  <Card icon={<TextCursor />} title="Native text selection">
    Drag to select in any pane, even inside apps that own the mouse
    (opencode's TUI, vim, less). Panes present as a plain `xterm-256color`.
  </Card>
  <Card icon={<Network />} title="Orchestration" href="/docs/guides/orchestration">
    `kumo agent wait/prompt/read` and `kumo pane wait-output` drive any pane
    and wait without polling.
  </Card>
  <Card icon={<FolderOpen />} title="Workspace-aware">
    kumo opens in the directory you launch it from; every new pane and
    session starts there.
  </Card>
</Cards>
