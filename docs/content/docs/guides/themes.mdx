Kumo ships a **theme picker**: a settings popup with tabs listing
Catppuccin-style schemes with light/dark variants, per-scheme backgrounds,
status-dot colors, and borders. Named colors (like `mauve`, `navy`) used by
the chrome and the sidebar git-branch flow through each scheme's secondary
accent instead of hardcoded constants.

Open it from the MENU button in the status bar.

<Callout type="info" title="Theme engine">
  Themes are user-editable in `config.toml`: define palette values for schemes,
  accents, status dots, and borders. The config file watcher applies theme
  changes without a restart; `kumo reload` remains available for an explicit
  refresh. See [Configuration](/docs/configuration).
</Callout>
